# Sosyo Akademi

Tanıştığın akademisyenleri unutmamak için kişisel kişi defteri. İlk sürüm sunucusuz: tüm kayıtlar yalnızca telefonda saklanır.

## iPhone'a kurulum
1. Safari'de uygulamanın adresini aç.
2. Paylaş düğmesine, sonra "Ana Ekrana Ekle"ye dokun.

## Yedek
"QR kartım" sekmesindeki "Dışa aktar" ile yedek dosyası alınır; "Yedekten geri yükle" ile geri yüklenir.
